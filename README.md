# Seafarer

Windows installer for Seafarer, a Unity 6 game by [Philip Dodson](https://philipdodson.dev). This repository only hosts release downloads; the source code is private.

**[Download Seafarer-Setup-1.0.exe](https://github.com/PhilipDodson2017/seafarer-releases/releases/latest/download/Seafarer-Setup-1.0.exe)** (28 MB, Windows 10/11, 64-bit)

You run a 14 m fishing workboat through rolling waves: walk the deck while it pitches and rolls, click the sea to set a course, haul nets, fend off drones, and keep answering your partner's texts before she worries.

## Install

1. Run `Seafarer-Setup-1.0.exe`. It installs for your user only, so no administrator prompt.
2. The installer is not code-signed, so Windows SmartScreen may say "Windows protected your PC". Click **More info**, then **Run anyway**.
3. Uninstall from Settings > Apps > Seafarer.

## Controls

| Key | Action |
|---|---|
| WASD, Shift, Space | Move, run, jump |
| Mouse | Look (Esc or L releases the cursor) |
| Left click | Fire |
| Right click | Sail to the crosshair (Shift + right click adds a waypoint) |
| X | Stop the boat |
| Tab | Chart view |
| E (hold, aft deck) | Deploy or haul a net |
| Q, then 1-3 | Open the phone and reply |
